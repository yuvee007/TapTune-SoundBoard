# TapTune-SoundBoard
Taptune is an interactive web app that lets users play sound effects with a single click. Built using HTML, CSS, and JavaScript, it showcases the use of the Audio API, button event listeners, and DOM manipulation, making it an ideal beginner-level project for learning web audio basics.

---

## ✨ Features

- 9 sound cards (Dog Bark, Pop, Laugh, etc.)
- Click on a card to play its sound
- Global volume slider
- Mute / Unmute button
- Simple, responsive UI layout

---

## 🛠 Technologies Used

- **HTML**
- **CSS**
- **JavaScript**
- JavaScript **Audio API** (`new Audio()`)

---

## ▶ How to Run

1. Download or clone this repository.  
2. Make sure the `sounds/` folder contains all required audio files (e.g., `dog.mp3`, `clap.mp3`, etc.).  
3. Open `index.html` in a web browser.  
   - Recommended: use a local server (e.g., VS Code **Live Server** extension).

🔗 **Live Demo / Project Link:** `https://yuvee007.github.io/TapTune-SoundBoard/`

---

## 🎓 Learning Outcomes

- Using the JavaScript Audio API to play sounds
- Handling click events with event listeners
- Working with `data-*` attributes for mapping UI to logic
- Updating UI state (active card animation, volume display)
- Building a small, complete front-end project
